# Validation workflow

Public users may submit field evidence through the future portal, but submissions should not directly become "Verified".

Recommended statuses:

- Submitted
- Under Review
- Verified
- Rejected
- Needs Revisit

Private submission details and restricted photographs should be stored outside the public GitHub repository. GitHub should contain only reviewed, public-safe validation summaries.

Required submission fields: coordinates, polygon/site, activity type, observation date, photos and comments. Only authorized reviewers may set Verified status; retain reviewer identity and status history in private storage. Another Sentinel-2 analysis is not required as independent validation of the Sentinel-2-derived Living Atlas classifications.
